# Claim 3 source audit

Theorem 3.12 states that for a **surjective homomorphism** `φ`, pullback
reflects post-fixed points for **any** abstract bundle. The direction is
`φ*h_Z ⪯ T_S(φ*h_Z) ⇒ h_Z ⪯ T_Z(h_Z)`.

Theorem 3.13 states that for a homomorphism `φ`, pushforward preserves
post-fixed points for **any** concrete bundle. The direction is
`h_S ⪯ T_S(h_S) ⇒ φ_*h_S ⪯ T_Z(φ_*h_S)`.

Both use Lemma 3.11's closure compatibility for liftings constructed with the
same operators. Pushforward additionally relies on the relevant joins in the
value preorder. These are premises, not conclusions silently assumed by the
certificate.

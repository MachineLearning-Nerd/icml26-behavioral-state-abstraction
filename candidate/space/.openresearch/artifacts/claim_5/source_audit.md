# Source audit

Proposition 4.1 is an immediate composition of transition preservation,
observation preservation, and probability-pushforward functoriality.

Proposition 4.2 rewrites model irrelevance as
`ker(f) <= ker(F_Moore(f) o t_S)` and uses the Set factorization criterion.
For a non-surjective encoder, the factor is first defined on the image. In the
standard nonempty MDP setting, `F_Moore Z` is nonempty, so it extends to unused
representation states. This implicit convention is stated explicitly here.

Proposition 4.3 avoids that extension issue because the quotient map of an
equivalence is surjective. Its two directions are exactly the kernel
factorization criterion and the homomorphism definition.
